# PostgreSQL 安裝與設定指南

## Windows 安裝步驟
1. 下載 PostgreSQL 16 版本：
   - 請至 [EnterpriseDB 官網](https://www.enterprisedb.com/downloads/postgres-postgresql-downloads) 下載 PostgreSQL 16 版。

## 安裝與設定步驟
1. 執行:
   ```zsh
   make sqlinstall_1
   ```
2. 在終端機執行以下指令以更新環境變數：
   ```zsh
   source ~/.zshrc
   ```
   然後執行
   ```zsh
   make sqlinstall_2
   ```
3. **Windows 使用者**：
   - 啟動 PostgreSQL server。
   - 在終端機輸入以下指令以進入 PostgreSQL：
     ```cmd
     psql -U postgres
     ```
   
 4.  如果成功，應該會看到提示符 `postgres=#`。

## 資料庫與帳號設定
1. 在 `postgres=#` 提示符下，輸入以下指令以創建資料庫（注意分號 `;` 必須放在指令結尾）：
   ```pgsql
   CREATE DATABASE rewardia_db;
   ```
2. 使用預設超級帳號：
   - 帳號：`postgres`
   - 密碼：`postgres`
3. **如需自訂帳號**：
   - 創建新帳號與密碼（注意分號 `;`）：
     ```pgsql
     CREATE USER 「帳號」 WITH PASSWORD '「密碼」';
     ```
   - 修改資料庫權限：
     ```pbsql
     ALTER SCHEMA public OWNER TO 「帳號」;
     ```
4. 連接到新創建的資料庫：
   - 在 `postgres=#` 輸入以下指令：
     ```pgsql
     psql -U 「帳號」 -d rewardia_db
     ```
   - 如果成功，應該會看到提示符 `rewardia_db=>`。
   - 退出 PostgreSQL 可輸入：
     ```pgsql
     \q
     ```

## 配置文件注意事項
- 確保 `.pg_service.conf` 中的 `user` 欄位與 `.pg_db_pass` 中的 `DBUSER:PASSWORD`（帳號:密碼）一致。
- 範例(以預設帳號為例)：
  - `.pg_service.conf`：`user = postgres`
  - `.pg_db_pass`：`postgres:postgres`

## 其他建議
- 執行 `make sqlinstall` 會下載官方 GUI 工具 **pgAdmin 4**。
- 安裝完成後，可使用 pgAdmin 4 完成上述操作，作為替代方式。
